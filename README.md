Lab 01 — The Event Loop Is the Game Loop

Браузерна гра з космічним кораблем, яким можна керувати за допомогою клавіатури.
Гра використовує фіксований крок симуляції 60 разів на секунду та requestAnimationFrame для відображення кадрів на Canvas

M1 — Ігровий цикл
Реалізовано функцію createLoop(), яка використовує:
requestAnimationFrame;
фіксований крок симуляції 1 / 60;
накопичувач часу
обмеження delta time;
інтерполяцію за допомогою alpha.

HUD показує:
Steps/s — кількість кроків симуляції за секунду;
FPS — кількість кадрів за секунду;

Frame time — час обробки останнього кадру.

M2 — Клавіатура та корабель

Обробка клавіатури реалізована за допомогою  createInput().
Корабель представлений звичайним JavaScript-об'єктом:
{x, y, vx, vy, angle, thrust}
Функція integrate(ship, input, dt) відповідає за:
поворот корабля;
прискорення у напрямку його руху;
гальмування;
обмеження максимальної швидкості.
Симуляція не залежить від Canvas.
При виході корабля за межі арени він з'являється з протилежного боку.

M3 — Інтерполяція та відображення
Реалізовано:
збереження попереднього та поточного стану корабля;
інтерполяцію між станами;
правильну інтерполяцію кута;
Canvas з урахуванням devicePixelRatio;
зміну розміру Canvas разом із вікном;
поворот корабля за допомогою translate() та rotate();
полум'я під час прискорення;
фонову сітку.

М4 - Експеременти 

М4.1
Для експерименту було додано синхронне блокування головного потоку на 100 мс кожні 60 кадрів.
Під час блокування гра короткочасно пригальмовує, а виконання JavaScript призупиняється, оскільки while займає головний потік. Через це event loop не може виконувати інші задачі до завершення блокуючого циклу.

Результат експерименту:
блокування: 100 мс;
Steps/s: близько 60;
FPS: зменшувався під час блокування;
у грі було помітне короткочасне підвисання. Цей момент якраз збігався з появою в консолі повідомлення Blocking: 100 m
Після завершення експерименту блокуючий код було видалено
Експеримент проводився у файлі blocking.js
